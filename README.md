# Mérida 2027

Sitio del grupo para el viaje a la boda de Clau y Diego en Yucatán (25 feb – 2 mar 2027): itinerario, datos de la boda, ruta, lugares, pendientes y costos.

## Estructura

- `index.html`: todo el sitio (HTML, CSS y JS, sin dependencias ni build).
- `favicon.svg`, `og.png`: ícono y vista previa al compartir el enlace.

## Verlo en local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
npx serve .
```

## Publicar

En Vercel: importar este repositorio. No requiere configuración; cada push a `main` se publica solo.
